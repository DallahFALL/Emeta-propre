Politique de confidentialité – e-META

Dernière mise à jour : 08/12/2025

1. Données collectées

Nous collectons uniquement les données nécessaires :

  • Identité : nom et prénom
  • Coordonnées : email, WhatsApp
  • Contexte : domaine, objectif, contraintes
  • Budget : montant + devise
  • Informations additionnelles : urgences, fichiers
  • Préférence : mode de restitution

2. Finalité du traitement

Les données servent exclusivement à produire une analyse IA personnalisée.

3. Durée de conservation

Les données sont supprimées après traitement ou anonymisées.

4. Sécurité

Les échanges sont protégés par chiffrement et accès restreint.

5. Vos droits

Vous pouvez demander la suppression de vos données via : contact@e-meta.app
